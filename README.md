# Проект «Холодильник»

Финальный проект первого спринта курса «Основы Python» в рамках программы «Прикладной искусственный интеллект» (Яндекс Практикум / УрФУ).

## Назначение проекта

Модуль для систематизированного учета продуктов питания в домашнем холодильнике. Позволяет хранить информацию о партиях закупок, отслеживать точные весовые и количественные остатки с использованием типа `Decimal`, парсить неструктурированные текстовые заметки и контролировать сроки годности.

## Основные функции

1. **`add(items, title, amount, expiration_date=None)`**
   - Добавляет партию продукта в словарь холодильника.
   - Поддерживает дату годности в строковом формате `'YYYY-MM-DD'` или `datetime.date`.
   - Точные вычисления количества продуктов через `Decimal`.

2. **`add_by_note(items, note)`**
   - Интеллектуальный парсинг текстовой заметки.
   - Автоматически распознает наличие или отсутствие срока годности в конце строки.
   - Поддерживает составные названия продуктов из нескольких слов (например, `"Яйца гусиные 4 2023-07-15"` или `"Вода питьевая 2.5"`).

3. **`find(items, needle)`**
   - Регистронезависимый поиск по названиям продуктов в холодильнике.
   - Возвращает список всех найденных наименований.

4. **`get_amount(items, needle)`**
   - Возвращает суммарное количество продукта по ключевому слову.
   - Суммирует все партии всех совпадающих товаров.

5. **`get_expired(items, in_advance_days=0)`**
   - Формирует список кортежей `[(название, количество), ...]` для просроченных продуктов.
   - Поддерживает параметр упреждения `in_advance_days`, позволяя выявить продукты, срок годности которых истекает сегодня, завтра или через N дней.

## Запуск демонстрации и тестов

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск интерактивного примера

```bash
python3 main.py
```

### Запуск автоматических тестов

```bash
pytest -v
```

### Проверка стиля кода

```bash
flake8 .
```
